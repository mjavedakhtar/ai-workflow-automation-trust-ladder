Automation / Safe AI Automation / Activate agent

Safe activation — "Ransomware → Isolate & Restore"

A destructive action (isolating an endpoint, restoring a backup) can never go from "off" to "autonomous" in one click. This flow forces scope, guardrails, and evidence-of-safety before the agent can touch production.

What the agent does

At 3am, EDR flags ransomware on an endpoint. Two agents work in sequence:

  1. Triage Agent — confirms it's real (encryption rate, ransomware note, known family), assesses which endpoint and how critical, and locates the most recent clean, verified backup from before the infection.
  2. Remediation Agent — proposes to isolate the endpoint (stop the spread) and restore from that clean backup, checks guardrails, then waits for one-click human approval.

Why it beats a human at 3am

  • Speed is the whole game. Ransomware spreads in minutes; a human on-call needs 15–40 to wake, connect, investigate, and find a clean backup. The agent compresses that prep to seconds — the human starts at "approve?", not "what's happening?"
  • Always on. One tech can't watch 50 clients' endpoints overnight — exactly when attacks fire. Agents triage all of them at once.
  • Removes error-prone glue work, not judgment. Hunting a backup that isn't itself encrypted is where a tired human slips. The agent verifies consistently; the human keeps the irreversible call.
  • Scales MSP economics. 24/7 response without night staff — the ROI story (shown to the Owner, not pressured onto the tech).

2 · Guardrails — the lines it cannot cross

These are enforced by the platform, not the model. Even a mis-reasoning agent is physically prevented from crossing them.

Script safety — try to break it 👇

Any command the Remediation Agent runs is checked against a certified allow-list by the platform. Edit the script and re-check — add something destructive like Remove-Item or Format-Volume and watch it get blocked.

4 · Choose the autonomy rung

You can move up the ladder any time as agreement holds. Given a 93.5% dry-run and a destructive action, L2 is recommended to start. Promotion is an Owner/Admin decision — a technician can't self-promote an agent.

RUNG 0

Shadow

Agent decides silently. Nothing acts. You compare against reality.

RUNG 1

Suggest

Agent drafts the action in the tech's queue. Human does everything.

RUNG 2 · RECOMMENDED

Approve-to-act

Agent prepares & waits for one-click human approval before acting.

RUNG 3

Auto + notify

Agent acts within guardrails, notifies you, fully reversible.

⏱ Time-boxed approvals. At L2, if no human responds within 15 min during an active ransomware event, the agent escalates to the on-call tech and PSA — it never silently drops a live threat.
